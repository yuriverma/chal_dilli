# The one runtime dependency list. It lives at the repo root because Hugging
# Face Spaces installs from the root, and it bind-mounts *only* this file into
# the build — so a `-r backend/requirements.txt` include here cannot resolve
# (it looks for /tmp/backend/requirements.txt and fails the build). Keeping a
# second copy under backend/ instead would just drift, so there is one file and
# everything points at it: the Dockerfile, render.yaml, nixpacks.toml and
# railway.json all install this.
#
# These pins need Python >= 3.11 (pandas 3.x does). A Gradio Space defaults to
# Python 3.10, which cannot install them at all, so README.md's frontmatter
# sets `python_version: "3.12"`. Check a change here against the target before
# deploying, rather than finding out from a failed build:
#
#   pip install --dry-run --only-binary=:all: --python-version 3.12 \
#       --target /tmp/check -r requirements.txt
